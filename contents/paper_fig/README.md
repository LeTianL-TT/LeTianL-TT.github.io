# Paper figures

These files are served locally with the homepage. To replace a figure, overwrite its image file or change the image path in both `contents/publications.md` and `contents/publications-all.md`.

- `neurips2025.png`: Figure 2 (method overview) rendered from the authors' [NeurIPS 2025 paper](https://proceedings.neurips.cc/paper_files/paper/2025/file/5cdf0bed49f637448eb8d18f40e14de0-Paper-Conference.pdf), page 4.
- `aaai2026.png`: E-Logic Prompt framework figure from the [coauthor's publication page](https://scs.tju.edu.cn/jswz/wanliang/20260429/publications.html), using its [public figure image](https://scs.tju.edu.cn/jswz/wanliang/20260429/paper/image/2026/e-logic-prompt-unified-energy-logic-framework-for-continual-visual-question-answering.png).
- `cvpr2026.png`: Figure 2 (Dynamic Alignment Graph Regularization) rendered from the authors' [CVPR 2026 paper](https://openaccess.thecvf.com/content/CVPR2026/papers/Tan_Towards_Dynamic_Modality_Alignment_in_Multimodal_Continual_Learning_CVPR_2026_paper.pdf), page 4.
- `icme2026.png`: Original figure provided locally by Tianle Liu.
- `ttd-hashing-memory.png`: Framework overview from the authors' [arXiv paper](https://arxiv.org/html/2503.10699v1), using its [original overview image](https://arxiv.org/html/2503.10699v1/overview.png). Paper: Fan Lyu, Tianle Liu, Zhang Zhang, Fuyuan Hu, Liang Wang, *Test-Time Discovery via Hashing Memory*, arXiv:2503.10699 (2025), CC BY 4.0.

The homepage does not fetch any of these images from an external site at runtime.
